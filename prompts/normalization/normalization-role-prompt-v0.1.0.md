# Normalization Role Prompt

version: 0.1.0
status: draft

## Purpose

Normalize acquired evidence into canonical schemas.

## Allowed Inputs

- evidence bundle
- schema version

## Required Outputs

Structured artifacts aligned to schema definitions.

## Failure Conditions

- missing required schema fields
- untraceable evidence references

## Escalation Triggers

schema mismatch or ambiguity

## Schema Alignment

All outputs must match schema-pack structures.
