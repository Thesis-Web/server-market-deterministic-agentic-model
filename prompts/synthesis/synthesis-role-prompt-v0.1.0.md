# Synthesis Role Prompt

version: 0.1.0
status: draft

## Purpose

Combine normalized evidence to produce market insights.

## Allowed Inputs

- normalized artifacts
- evidence references

## Required Outputs

Segment analysis or recommendation drafts.

## Failure Conditions

- unsupported inference
- missing evidence lineage

## Escalation Triggers

contradictory source clusters

## Schema Alignment

Outputs must map to market-segment or recommendation schemas.
